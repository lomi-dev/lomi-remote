# Remote v1 specification

The [specification snapshot](remote-server/README.md) preserves the Markdown
files from the sibling `remote-server` directory. `remote-server/SOURCE.json`
records their exact source hashes. Original workspace-relative links are
retained; local runtime evidence is not part of this source export.

Historical status in that snapshot applies to its recorded checkpoints. Read
the [current implementation handoff](../implementation/technical-handoff.md)
and [delivery status](../implementation/delivery-status.md) for current source,
compilation and qualification limits.
