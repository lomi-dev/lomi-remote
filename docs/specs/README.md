# Remote v1 specification

The [specification snapshot](remote-server/README.md) preserves the Markdown
files from the sibling `remote-server` directory. `remote-server/SOURCE.json`
records their exact source hashes. Original workspace-relative links and the
snapshot's historical status notes are retained; they are not current release
or qualification records.

Current product source is under `crates/`. Release installation and update
procedures are in `release/README.md`; operator recovery guidance is in
`docs/operations/recovery.md`.
